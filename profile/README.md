<h1 align="center">DemoBites</h1>

<p align="center"><strong>You prompt, it records.</strong></p>

<p align="center">
Describe a product demo in one sentence. An AI agent films it in a real
browser, with a real cursor, on real pages. DemoBites turns the take into a
fully editable bite: AI narration, cinematic zooms, a rendered cursor, intro
and outro, all tweakable in a studio. The last five percent is a five second
drag, never a re-shoot.
</p>

```bash
npx demobite@latest
```
